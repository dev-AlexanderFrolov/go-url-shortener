# Наш план обучения (Roadmap): URL Shortener

## ✅ ПРОЙДЕНО (Уровень: База)
1. **Основы + Docker:** Написали API на Go, завернули приложение в Docker.
2. **База данных и Docker Compose:** Подняли PostgreSQL в контейнере, настроили проброс портов (Port Mapping) и Volumes для сохранения данных.
3. **Управление конфигурацией (.env):** Научились передавать доступы (DATABASE_URL) через переменные окружения, спрятав секреты из кода.
4. **Миграции БД (golang-migrate):** Настроили автоматическое создание таблиц при старте сервера, отказавшись от ручных скриптов.
5. **Архитектура (Clean Code):** Разбили монолитный `main.go` на слои: роутеры (Handlers), бизнес-логика (Services) и работа с БД (Repositories).

## 🚀 В ПРОЦЕССЕ (Уровень: Архитектура и Оптимизация)
6. **Dependency Injection (DI):** Рефакторинг. Избавимся от глобальной переменной `db`. Научимся правильно "прокидывать" зависимости в Go через структуры, чтобы код был чистым и готовым к Unit-тестам.
7. **Кэширование (Redis):** Поднимем Redis в Docker Compose. Добавим слой кэширования, чтобы ускорить редиректы и не мучать Postgres при каждом клике на популярную короткую ссылку.

## 🛠️ БУДУЩЕЕ (Уровень: DevOps и Продакшен)
8. **Автоматизация и Деплой (CI/CD):** Напишем GitHub Actions. При каждом `git push` в ветку `main` код будет автоматически тестироваться, собираться в Докер-образ и выкатываться на реальный сервер (VPS).
9. **Введение в Kubernetes (K8s):** Финальный босс. Разберемся, чем K8s отличается от Docker Compose. Напишем манифесты (Deployments, Services) и попробуем запустить наш микросервис в локальном кластере (Minikube/Kind), имитируя реальный BigTech-продакшен.
